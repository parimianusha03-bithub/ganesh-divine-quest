# Ganesh's Divine Quest — Version 2

Enhanced Ganesh Chaturthi game prototype for the Game Design Contest.

## Files
- index.html — game structure and festive screens
- style.css — festival visuals, animations and responsive mobile layout
- game.js — gameplay, levels, score, lives and controls

## Controls
Desktop: Left/Right arrows, Up/Space to jump, P to pause.
Mobile: on-screen buttons.

## Current version
Collect flowers, diyas and modaks, avoid rocks, unlock 3 levels, and reach the Divine Quest victory screen.

## Step 5 upgrade
The prototype now includes a richer Ganesh Chaturthi festival look with garlands, diyas, temple backdrop, glowing effects, improved buttons, animated player styling and level-unlock feedback.
