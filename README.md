# Ganesh's Divine Quest — Version 1

First playable prototype for the Ganesh Chaturthi Game Design Contest.

## Files
- index.html — game structure
- style.css — visuals and mobile layout
- game.js — gameplay logic

## Run
Open `index.html` in a modern browser.

## Controls
Desktop: Left/Right arrows, Up/Space to jump, P to pause.
Mobile: on-screen buttons.

## Current prototype
Collect flowers, diyas and modaks, avoid rocks, and progress through 3 levels.
